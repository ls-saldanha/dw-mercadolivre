# Walkthroughs

One file per milestone. Each file is a chronological log of checkpoints — what was built, what concepts appeared, what broke and how it was fixed.

## Format

Each entry follows this structure:

```
## [YYYY-MM-DD] Checkpoint: <title>

**What we built:** 1–2 sentences.
**Files touched:** bullet list.
**New concepts introduced:** concepts that appeared for the first time, with a one-line reminder.
**Patterns reused:** patterns from earlier in the project that recurred.
**What broke and how we fixed it:** real bugs, real fixes. If nothing broke: "No specific breakage documented."
**Decisions logged:** ADR-NNNN if any ADR was written.
**Next step:** one sentence.
```

Fields marked `[inferred]` were reconstructed from repo state rather than recorded at the time.
